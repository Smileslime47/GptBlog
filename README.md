# 47Saikyo 文章

本分支管理文章和附属资源，不使用 GitHub Pages。

- `posts/`：Markdown 文章及相对路径配图。
- 原站 100 个附属资源已归档；当前生产文章在后台配置同步凭据后点击“迁移当前文章到仓库”导入，以保留最新修改和草稿。
- 在站点设置中配置秘密变量 `GITHUB_POSTS_TOKEN`（仅 GptBlog 的 Contents 读写权限）。
- 本地编辑推送后，到 `/admin` 点击“从仓库同步”；每批最多 10 篇，直至剩余为 0。
- 网站源码与使用说明在 `main` 分支，D1 为可重建的阅读缓存。
- 草稿会随仓库公开性公开，网站只隐藏草稿的读者入口。
- 原文与资源许可保持 CC BY-NC-SA 4.0。
